# ReelRank
A personal, mobile-first movie ranking app.

This repository hosts the installable ReelRank website through GitHub Pages. The catalog is kept in Lovable Cloud and user scores are stored on the device.

## iPhone
Open https://gianobrook.github.io/ReelRank-/ in Safari, tap **Share**, then choose **Add to Home Screen**.

## Publishing
This repository uses GitHub Actions at `.github/workflows/pages.yml` for Pages deployment.
